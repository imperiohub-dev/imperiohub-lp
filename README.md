# @imperiohub/lp

A React component library built with TypeScript and Vite.

## Installation

```bash
npm install @imperiohub/lp
```

## Usage

```tsx
import { } from '@imperiohub/lp'

// Your code here
```

## Development

Install dependencies:

```bash
npm install
```

Build the library:

```bash
npm run build
```

Run development mode:

```bash
npm run dev
```
